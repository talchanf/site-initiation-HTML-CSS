# Non-Non drogue : site d'information sur les addictions

Site web statique réalisé pour apprendre le HTML et le CSS. Il rassemble des articles d'information et des témoignages sur les addictions.

## Contenu du site

- Page d'accueil (`home.html`) avec la liste de tous les articles
- Cinq articles : qu'est-ce que l'addiction, la drogue dure, la drogue douce, les addictions du quotidien, et un centre d'aide
- Des pages de témoignages classées par thème (drogue dure, drogue douce, drogue du quotidien)
- Un tableau de statistiques (`tab_stats.xlsx`) qui a servi à illustrer le propos

## Technologies

HTML, CSS (`styles.css`), polices Google Fonts (Michroma, Oswald, Open Sans). Les photos viennent de [Pexels](https://www.pexels.com).

## Ouvrir le site

Ouvrir `home.html` dans un navigateur. Aucune installation n'est nécessaire.

## Ce que j'ai travaillé

- Structurer un site de plusieurs pages avec des liens internes.
- Mettre en forme avec une feuille de style commune.
- Organiser des contenus en dossiers (articles, témoignages, images).
